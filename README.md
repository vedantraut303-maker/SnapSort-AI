# SnapSort AI — Intelligent Visual Understanding System

SnapSort AI is a computer-vision application using YOLO11n for object detection, analytics, privacy-aware processing, detection history, and automated PDF reporting.

## Features
- YOLO11n object detection
- Image and camera input
- Object counting
- Confidence analysis
- Smart scene understanding
- Privacy mode with person blurring
- Detection history
- Automated PDF reports
- Professional Streamlit UI
- ONNX model workflow
- Qualcomm AI Hub compilation and profiling

## Technology Stack
- Python
- YOLO11n
- Ultralytics
- OpenCV
- Streamlit
- ONNX
- Qualcomm AI Hub
- Snapdragon X Elite target profiling

## Qualcomm AI Hub
Target device: Snapdragon X Elite CRD

AI Hub profiling:
- Estimated inference time: 6.878 ms
- Estimated peak inference memory: approximately 40.4 MiB
- First-load time: approximately 5.07 s

These are Qualcomm AI Hub target-device profiling results, not measurements from the developer's local PC.
